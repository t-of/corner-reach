CORNER REACH

角だけでつなぐ陣取り

T.OF... のアプリ・問い合わせ
あなた 0 マス
CPU 0 マス

遊び方

  1. あなたと CPU が、21 個のブロックを 1 つずつ交互に盤へ置きます。
  2. 最初のブロックは、自分の「はじまりのマス」（丸い印）を覆うように置きます。
  3. 2 つ目からは、自分のブロックと角だけで触れるように置きます。自分のブロックと辺でくっついてはいけません。相手のブロックとはどう触れてもかまいません。
  4. 置けなくなったら自動でパス。ふたりとも置けなくなったら終わりです。盤に置いたマスが多いほうの勝ち。

操作

  • 下の手持ちからブロックを選ぶと、盤に影が出ます。
  • 盤をなぞると影が動きます。マスをタップするとそこへ移ります。
  • ［回す］［裏返す］で向きを変えて、［置く］で決めます。
  • 盤の小さな点は、あなたが次に使える角です。
