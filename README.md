# カドツギ — 角だけでつなぐ陣取り

ブロックを角と角だけでつないで広げていく、CPU とのふたり陣取り。相手より多くのマスを盤に置けたら勝ち。

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/kadotsugi/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

1. あなたと CPU が、21 個のブロックを 1 つずつ交互に 13×13 の盤へ置く。
2. 最初のブロックは、自分の「はじまりのマス」（丸い印）を覆うように置く。
3. 2 つ目からは、**自分のブロックと角だけで触れる**ように置く。自分のブロックと辺でくっついてはいけない。相手のブロックとはどう触れてもよい。
4. 置けなくなったら自動でパス。ふたりとも置けなくなったら終わり。**盤に置いたマスが多いほうの勝ち**。

操作（スマホはタッチだけで遊べる）

- 下の手持ちからブロックを選ぶと、盤に影が出る
- 盤をなぞると影が動く。マスをタップすると影の中心がそこへ移る
- ［回す］［裏返す］で向きを変え、［置く］で決める（置けない位置では影に斜線と赤い縁が出る）
- 盤の小さな点は、自分が次に使える角。どこにも置けないブロックは薄くなる
- PC: R 回す / F 裏返す / Enter 置く / 矢印で動かす

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

一度開けば、オフラインでも遊べます。

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
```

| ファイル | 中身 |
|---|---|
| `game.js` | 遊びの中身（置ける判定・パス・終わり・得点・CPU）。DOM に触らない |
| `main.js` | 画面と操作 |
| `test.mjs` | `game.js` のテスト |

テスト（Node 18 以上、インストール不要）:

```sh
node test.mjs
```

CPU の強さは `game.js` の `CPU`（点の係数）で変えられる。

記録は端末の localStorage に保存する（`kadotsugi.stats`: 戦績、`kadotsugi.settings`: 遊び方を見たか）。
